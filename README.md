# 🎥 OpenCV Webcam Video Recorder

A simple Python project using OpenCV that captures live webcam video and optionally records it into an MP4 file.

---

## 🚀 Features

- 📷 Live webcam capture
- 🎬 Optional video recording
- 💾 Save recorded video in `.mp4` format
- ⌨️ Press `r` to stop recording or exit preview
- ⚡ Beginner-friendly OpenCV project

---

## 🛠️ Technologies Used

- Python
- OpenCV (`cv2`)
